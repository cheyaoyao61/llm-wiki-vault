# 物流规划方法论

物流规划是在企业物流实战中运用物流管理知识与运筹方法，指导建设或优化物流实体与流程的过程。其核心价值在于帮助企业**降本增效**，提高物流服务质量与效率。

## 物流规划的四大应用场景

1. **物流运作管理与操作**：指导何时、何地、用什么步骤完成物流活动；优化流程合理性、物料分类、功能区设置
2. **物流资源采购与应用**：决策设备类型、数量、自动化程度；避免资源浪费或爆仓瓶颈
3. **物流设施建设**：选址（城市/区域）、仓库类型（平库/立体仓库）、库容面积规划、内部功能区布局
4. **物流信息化建设**：为WMS等系统提供业务流程设计基础；运作策略通过算法落地

## 物流规划系统性分析框架

物流规划方法模型包含九大要素：

| 要素 | 说明 |
|------|------|
| 供应链业务模式 | 物流服务的背景框架（MTS/MTO/ETO/DTR） |
| 供应链的流程 | 明确上下游关系，知道物流需求何时触发 |
| 供应链组织 | 确定相关岗位，获取数据和业务信息 |
| 供应链的角色 | 定位在供应链网络中的位置 |
| 物流环节 | 与SCOR一级流程对应（采购/生产/销售/回收） |
| 物流活动 | 具体的流程动作（卸货/理货/上架/分拣/配货/装车等） |
| 物流指标 | 量化评价每个物流活动的状态 |
| 物流字段 | 信息系统中记录的业务数据名 |
| 物流数据分析 | 特征分析、数量计算、效率分析、仿真模拟等 |

## 物流规划九步法（问题分析逻辑）

1. **发起**：由客户或内部部门提出物流问题（可来自战略层，再拆解到职能层）
2. **定义范围**：明确涉及的内外部组织和部门
3. **找关键指标**：以结果为导向，梳理核心KPI及相关指标，建立评价标准
4. **建立变量**：明确指标计算方法和所需变量
5. **梳理物流活动**：确认变量来自哪些具体的物流业务活动
6. **获取数据**：与相关岗位人员沟通，获取计算数据和业务信息
7. **优化策略**：调整物流活动，通过KPI计算结果判断正负向，迭代至最优方案
8. **跨部门协同**：将方案与相关部门沟通，确保可行性
9. **建立监控机制**：将逻辑和计算方法模型化，持续监控运行情况

## 物流中心运作

物流中心是物流节点的核心类型，标准作业流程：

```
卸货 → 理货（单元化整理）→ 上架/库存管理 → 分拣 → 配货/包装/流通加工 → 装车
```

**关键功能**：装卸搬运、上架、分拣、配货、包装、流通加工、配送

**信息化要求**：每个步骤需与信息系统交互，记录操作过程和数据

## 物流资源分类

- **存储设备**：货架（平库/高位货架/立体自动仓库）
- **搬运设备**：液压叉车、高位叉车、AGV
- **自动化设备**：自动分拣系统、RFID、条形码扫描
- **运输设备**：车辆（按品类和批量选配）
- **人员**：拣货员、叉车操作员、仓管员等

## 物流规划关键数量计算

### 仓储面积计算
需考虑：库存量（峰值/均值）× 单位货物占地 + 通道面积 + 功能区面积（收货/发货/暂存/包装等）

### 设备数量计算
基于：日处理量 ÷ 单台设备效率 × 利用系数（考虑波动系数）

### 物流需求波动分析
- 识别需求波峰（季节性、促销、节假日）
- 建立安全库存和基准库存
- 计算资源配置的弹性需求范围

## 物流网络规划指标

| 类型 | 典型指标 |
|------|----------|
| 网络规划 | 配送覆盖率、运输成本率、交付时效 |
| 节点规划 | 库容利用率、作业效率（件/人/小时）、准确率 |
| 运作执行 | 库存周转率、订单履行率、仓储成本率 |

## 企业物流规划与各部门关系

物流规划师需与以下部门协同：
- **生产部**：物料需求发起，JIT配送要求
- **销售/市场部**：需求预测，订单模式
- **采购部**：供应商交付方式，来料批量
- **工程部**：生产工艺流程，物料规格
- **财务部**：库存持有成本，资金周转要求
- **IT部**：信息系统对接，数据接口标准
