# 供应链基础概念

供应链是以客户需求为导向，以提高质量和效率为目标，以整合资源为手段，实现产品设计、采购、生产、销售服务等全过程高效协同的组织形态。现代供应链已与互联网、物联网、人工智能、大数据深度融合，演进为智慧供应链。

## 什么是供应链

供应链不是一个链条，而是一个生态网络——由原材料供应商、生产商、批发商、零售商及最终消费者组成的供需网络。核心要素包括：

- **核心企业**：产品制造企业或大型零售企业
- **节点企业**：各层级供应商、经销商、物流服务商
- **四大流**：物料流、信息流、资金流、商流

## 供应链的五大流程（SCOR框架）

| 流程 | 英文 | 核心内容 |
|------|------|----------|
| 计划 | Plan | 平衡需求与供应，制定需求/采购/生产/配送/退货计划 |
| 采购 | Source | 选择供应商，管理从报价到付款的全流程 |
| 生产 | Make | 原料到产成品，含发料、生产、检测、包装、发货 |
| 交付 | Deliver | 产成品从工厂到客户，含订单确认、运输、安装 |
| 退货 | Return | 缺陷产品识别、处置、退货运输 |

→ 详见 [[SCOR供应链运作参考模型]]

## 供应链的角色

**五类角色**：供应商 → 生产商 → 分销商 → 零售商 → 消费者

- **供应商**：提供原材料，其生产能力和物流供应能力对整条链影响大
- **生产商**：物料需求发起者，推式供应链中产线能力决定物流运作强度
- **分销商**：承上启下，决定下游物流效率（互联网环境下有时省略）
- **零售商**：直接服务终端消费者
- **消费者**：供应链唯一收入来源

## 供应链业务模式

| 模式 | 全称 | 特点 |
|------|------|------|
| MTS | 按库存生产 | 预测驱动，需高准确需求预测，通常配合CPFR/S&OP/VMI |
| MTO | 按订单生产 | 订单触发，常以半成品备货缩短交期 |
| ETO | 工程定制 | 含产品设计过程，周期最长 |
| DTR | 零售配送 | 配送中心→零售超市，有一定产成品库存 |

## 供应链管理目标

> 在正确的时间，将正确的产品，以正确的质量、正确的数量和正确的状态，发往正确的地点，并实现总成本最低。

## 供应链与物流的关系

供应链运作串联在四类物流活动中：

1. **采购物流**：供应商→生产商（原料供应），可采用循环取货（Milkrun）
2. **生产物流**：物料中心→生产线，精益生产中用JIT控制在制品库存
3. **销售物流**：物流中心→零售商/终端客户，仓储管理要求高
4. **回收物流**：不合格品或退货的逆向物流，与退货流程衔接复杂

## 供应链管理六大核心模块

1. 市场与客户需求管理（需求订单管理）
2. 产品开发管理（与客户/供应商协同开发）
3. 计划与需求管理（平衡供需、EOQ设计）
4. 采购与供应管理（供应商选择、KPI评价）
5. 生产与运营管理（产线规划、生产控制）
6. 仓储与物流管理（进出存管理、库存周转）
